## 🛠️ Despliegue Rápido

Este sitio es un sitio estático puro (HTML5 + CSS nativo + JS ligero). Puedes desplegarlo en 1 minuto en cualquiera de las siguientes plataformas:

1. **GitHub Pages:**
   - En este repositorio ve a **Settings** > **Pages**.
   - En **Source**, selecciona `Deploy from a branch` y elige la rama `main` (carpeta `/root`).
   - Tu sitio estará activo en `https://francoleon785-sys.github.io/<nombre-repo>/`.

2. **Netlify:**
   - Arrastra la carpeta completa a [app.netlify.com/drop](https://app.netlify.com/drop).

3. **Vercel:**
   - Importa este repositorio desde el panel de [vercel.com](https://vercel.com).
